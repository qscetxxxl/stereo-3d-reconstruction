# stereo-3d-reconstruction

**About**

A computer vision web app that takes two stereo images as input and generates a disparity map, colorized depth heatmap and a fully colored 3D point cloud.

**Tech Stack**

* Python
* OpenCV
* Open3D
* Streamlit
* NumPy

**How to Run**

```bash
pip install -r requirements.txt
streamlit run app.py
```

**Features**
- Upload any two stereo images

- Generates disparity map

- Generates colorized depth heatmap

- Generates downloadable 3D point cloud (.ply)
